# Registro Austral

Sitio público del **Registro Austral**, observatorio de fenómenos aéreos anómalos (FANI/UAP)
con foco en Chile, la Patagonia y el cono sur.

Archivo y vigilancia de fuentes oficiales y académicas: SEFAA y DGAC (Chile), CEFAE
(Argentina), GEIPAN (Francia), AARO y NARA (Estados Unidos), Aeronautica Militare (Italia),
Arquivo Nacional (Brasil), Ministerio de Defensa (España), además de repositorios
académicos y prensa establecida.

## Sobre este repositorio

**Todo el contenido de este repositorio es generado automáticamente.** No se edita a mano:
se produce desde una base de datos propia mediante un generador estático, y se republica
cuando hay novedades. Cualquier cambio manual se perderá en la siguiente publicación.

Sitio estático puro: HTML y una hoja de estilo, sin JavaScript, sin dependencias externas
y sin rastreadores.

## Licencia y uso

Los documentos citados pertenecen a sus organismos y medios de origen; aquí se enlazan y
contextualizan. Los textos de análisis son obra del Registro Austral. Para citar el
archivo, indica siempre la fuente original de cada documento, enlazada en cada entrada.
